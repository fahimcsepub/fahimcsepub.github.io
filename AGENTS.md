# Agent instructions

Before changing this repository, read [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) completely. It is the durable project handoff for architecture, product rules, current status, testing, and deployment.

For work on the certificate generator, also read [`automations/certificates-awards/certificate-generator/README.md`](automations/certificates-awards/certificate-generator/README.md). For a new automation module, read [`docs/ADDING_AN_AUTOMATION.md`](docs/ADDING_AN_AUTOMATION.md).

Keep `PROJECT_CONTEXT.md` current whenever a change alters architecture, official wording, templates, CSV fields, deployment, or an important product decision. Never place student data, real signatures, credentials, private registers, or other sensitive material in repository documentation.
