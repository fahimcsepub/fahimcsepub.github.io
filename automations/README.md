# Automation Catalog

Use this directory to locate departmental automations by function. A module marked **Live** is deployed and tested; **Planned** identifies a category reserved for future development.

## Certificates & Awards

| Automation | Status | Purpose | Documentation |
|---|---:|---|---|

Suggested future modules include semester dashboards, accreditation evidence summaries, and non-sensitive departmental statistics.

## Catalog rules

- Add every automation to exactly one primary category.
- Use a short kebab-case folder name, such as `publication-register`.
- Give every module its own README, app or scripts, references, and non-sensitive samples where applicable.
- Identify the module owner, lifecycle status, inputs, outputs, privacy behavior, and deployment method.
- Update this catalog whenever a module is added, renamed, deprecated, or replaced.

See [Adding an Automation](../docs/ADDING_AN_AUTOMATION.md) for the required structure and checklist.
